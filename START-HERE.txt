╔══════════════════════════════════════════════════════════════════════════════╗
║                          🐛 TROUBLESHOOTING                                  ║
╚══════════════════════════════════════════════════════════════════════════════╝

   Problem: "Python not found"
   → Install Python from https://www.python.org/
   → Make sure to check "Add Python to PATH"

   Problem: "Node.js not found"  
   → Install Node.js from https://nodejs.org/
   → Use LTS version (recommended)

   Problem: Installation fails
   → Check INSTALLATION-GUIDE.md (Section: Troubleshooting)
   → Make sure you have 2 GB free space
   → Check your internet connection

   Problem: Services won't start
   → Ports might be in use - close other programs
   → Check terminal output for error messages
   → Try STANDALONE-MODE instead

   Problem: "Loading script failed" error
   → Wait longer (15-20 seconds) for all services to start
   → Refresh the browser page
   → Check all terminal windows are still running
